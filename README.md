# 🏥 Sistema de Gestión - Clínica Santa Mónica

Este es el ecosistema digital para la administración de la Clínica Santa Mónica, construido con una arquitectura desacoplada de alto rendimiento.

## 🛠️ Stack Tecnológico
* **Backend:** .NET 9 Web API (Arquitectura Limpia / Clean Architecture)
* **Frontend:** Blazor WebAssembly (UI con MudBlazor)
* **Base de Datos:** PostgreSQL en la nube (Neon.tech)
* **ORM:** Entity Framework Core
* **CI/CD:** GitHub Actions + SonarCloud
* **Despliegue:** Azure App Service (API) & Azure Static Web Apps (Front)
